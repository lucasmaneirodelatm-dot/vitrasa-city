# API

## Objetivo

Controlar una o varias ciudades VITRASA desde una única API.

## Version

0.1

## Estado

En diseño.

## Dirección actual

https://vitrasa-api.lucasmaneirodelatm.workers.dev/

## Módulos previstos

- /ciudad
- /bus
- /parada
- /semaforo
- /tren
- /paso-nivel
- /cochera
- /farola
- /evento
- /configuracion

## Futuras funciones

- Obtener estado de una ciudad.
- Obtener estado de un autobús.
- Cambiar un semáforo.
- Abrir o cerrar puertas de un autobús.
- Conocer la posición de todos los vehículos.
- Gestionar varias ciudades al mismo tiempo.
